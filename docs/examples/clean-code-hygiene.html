Source hygiene worked example

Summary

A disposable input containing a direct print call and a bare exception handler produces two findings. Replacing the print with a logger call and specifying the exception type produces zero findings. These results satisfy the example's hand-counted criteria; they do not qualify an engineering calculation.

Inputs

The baseline is an empty JSON object in each input tree. No legacy exception applies. Neither input is imported or executed.

Before

try:
    print("Process START")
except:
    pass

After

import logging

logger = logging.getLogger(__name__)
try:
    logger.info("Process START")
except ValueError:
    raise

Method and expected answer

The source is parsed into an abstract syntax tree and compiled in memory without execution. A direct call named print is counted once; an ExceptHandler whose type is absent is counted once. Comments and quoted spellings contribute no nodes of those kinds.

Reproduce

From the repository root, select an unused output directory outside the checkout:

python3 examples/hygiene/clean_code.py --output-dir "$TMPDIR/hygiene-example"

Expected output: PASS: before has 2 findings; after has 0 findings. The command exits with zero only when both observations match Table 2. An existing output directory is refused without overwriting its files.

The output directory retains before/ and after/ source trees, each checker's checker.txt, and a combined results.json. No generated output needs to be committed.

Sources and limits

The Python documentation, version 3.9, defines Call and ExceptHandler. The parse warning requires additional compilation for contextual syntax errors. No physical equation, engineering coefficient or acceptance limit is used here.

The syntactic check does not resolve aliases or determine whether a logger message or exception choice is appropriate. The replacement handler illustrates syntax only; it does not imply that logging raises this exception.
