Compound Engineering trial plan

The trial will separate evidence preparation from observed plugin behavior. The source criteria will remain those in the trial epic. No plugin result will be inferred from tests of the evidence tooling.

Proposed scope

  1. A standard-library validator in scripts/evaluation/compound_trial.py will read a trial record, require the epic's complete criterion set, and preserve PASS, FAIL, and NOT_EVALUATED separately.
  2. The validator will check local evidence digests and reject malformed records, missing artifacts, links escaping the evidence root, and unsupported versions. It will return readiness for maintainer review only when all criteria pass; it will never authorize installation or rollout.
  3. A worked example, trial assessment, and reusable solution note will describe the remaining live trial and the per-repository guardrails. Local plugin configuration will be ignored without installing or invoking the plugin.

Basis and tests

No engineering equations or empirical coefficients will be introduced. Criterion membership will come from the epic's success criteria; details will come from its linked setup, worktree, advisory, pipeline, and decision issues. Synthetic tests will enumerate expected counts by hand and will label their evidence as synthetic. They will exercise the command-line interface, including incomplete, failed, complete, malformed, and tampered evidence.

Adversarial plan checks

The design will be challenged against false adoption claims, arbitrary status strings, incomplete criterion lists, stale or missing evidence, absolute paths, parent traversal, symlink escapes, duplicate JSON keys, and unverified plugin revisions. Evidence hashes will establish byte agreement only; they will not authenticate statements or a reviewer's judgment.

Remaining live trial

The actual user-scoped installation and assistant-driven skills will remain outside this implementation. The assessment will mark their outcomes NOT_EVALUATED. A maintainer will resolve the requested plugin version, run the isolated trial, capture observations, obtain independent review, and decide adoption before any rollout.
